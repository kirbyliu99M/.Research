# 問卷隨機導向頁

單一靜態頁（`index.html`），部署在 GitHub Pages，網址：<https://survey.kirby-fivesenses.com>。

受試者只拿到一個網址；頁面在瀏覽器端把人隨機導到 4 份 Google 表單之一，讓不支援隨機分派的 Google 表單也能做分組。

> ⚠️ **這個 repo 是公開的**（免費 GitHub Pages 的限制）。只放網頁本身，**不要放**研究文件、假設、刺激圖原檔、受試者資料或個人資訊。

## 目前對應的版本

| 代號 | 誘因 | PSE 區塊順序 |
|---|---|---|
| A1 | 一般會員 | 低機敏先 |
| A2 | 一般會員 | 高機敏先 |
| B1 | 會員＋首購 30% 折扣 | 低機敏先 |
| B2 | 會員＋首購 30% 折扣 | 高機敏先 |

前測與正式施測共用同一組表單，資料由研究者自行區分。

## 運作方式

1. 開啟頁面時，用 `crypto.getRandomValues`（無法使用時退回 `Math.random`）等機率抽出 4 版之一（2³² 可被 4 整除，機率相等）。
2. 抽到的版本存在瀏覽器 `localStorage`（key：`survey_arm_v2`）。同一瀏覽器重新整理或再點連結，一律導回同一版。無法使用 `localStorage`（私密模式等）時不報錯，直接隨機。
3. 播放約 2 秒的進場動畫後用 `location.replace` 跳轉；動畫期間不會等待也不影響分派。校徽在跳轉前一直顯示，網路慢時不會先變空白。若 3 秒後仍在此頁，會出現「點此繼續」備援連結。
4. **不蒐集任何資料**：沒有分析工具、追蹤碼、Cookie、外部字型或外部腳本，頁面不送出任何請求（只讀取同網站的圖檔）。`noindex, nofollow` 與 `no-referrer` 已設定。

## 常用修改（都在 `index.html`）

- **換表單網址**：改 `<script>` 最上方的 `ARMS`。
- **重新分派所有人**（例如表單改版）：把 `KEY` 的 `survey_arm_v2` 改成 `v3`。
- **動畫長度**：`DELAY`（毫秒，預設 2000）。
- **網站名稱／預覽圖**：`<title>` 與 `og:`、`twitter:` 標籤；預覽圖是 `og.png`。更換網域時，`og:url`、`og:image`、`twitter:image` 的絕對網址要一併改。
- 改完 push 到 `main`，Pages 約 1 分鐘內更新。LINE、Facebook 會快取連結預覽，更換預覽圖後需用各平台的除錯工具重新抓取。

## 網域與 HTTPS

- DNS：`survey` 的 **CNAME** 指向 `kirbyliu99m.github.io`（網域在 Cloudflare，需設為 **DNS only**，不要開橘色雲朵）。
- Settings → Pages 已啟用 **Enforce HTTPS**。憑證由 GitHub 自動續期；若網域異動，需重新確認憑證。

## 🔔 提醒：有新的研究要上線，或這份研究結束時，請先撤下這個專案

這個 repo 是「研究的轉址器」，網址會被印出或轉傳，**研究結束後仍會一直把人導向舊問卷**。有新的研究專案要接手，或這份問卷收案結束時，依序處理：

1. **先關閉舊表單收件**：四份 Google 表單都關閉「接受回應」，並記錄關閉日期（供論文說明）。
2. **撤下舊專案的導向**：
   - 要接新專案：換掉 `ARMS`、`KEY` 改版號（`v3`…）、更新 `<title>`、`og:` 標籤與 `og.png`，確認頁面文字與預覽圖沒有留下舊研究的名稱。
   - 不再使用：把頁面改成中性的「問卷已結束」說明頁（不導向任何表單），或直接刪除 repo。
3. **同時存在多個專案時**：不要共用同一個網址分派；每個專案用獨立子網域，或在子資料夾放自己的 `index.html`（例如 `/<project>/index.html`），各自有自己的 `KEY`。
4. **如果停用網域或刪除 repo**：先刪掉 DNS 的 `survey` CNAME 記錄。DNS 指向已不存在的 GitHub Pages 站點，會讓別人有機會接管這個子網域。
5. **檢查公開內容**：repo 與歷史紀錄中不得出現研究文件、假設或受試者資料。
6. 把撤下日期與原因記進研究紀錄（工作區進度檔）。
